## Changes without API spending

- An owner-only, no-store `GET /api/recordings/:id/review` derives a comparison from the immutable saved transcription and analysis. It performs no model request or database update.
- The uploaded-meeting summary offers original-versus-reviewed task details, verbatim evidence and precise source seeking. Explicit details can be applied to editable workspace tasks and restored to original extraction values. Original recording transcript, analysis and meeting JSON remain unchanged.
- Conservative assignment grammar recovers literal names and `by WEEKDAY` only from that action's cited utterance. Existing non-null fields are preserved; no calendar dates or attendee identities are inferred. The UI marks first-person responsibility as identity unknown.
- Summary bullets now retain individual source timestamps. Existing records receive corrected links in the derived review; future processed meetings receive them directly.
- Six source-backed moment suggestions are shown separately from existing annotations. Adding a suggestion is explicit. New manual, original automatic and review-derived highlights carry/display distinct provenance; legacy records remain readable without rewriting.
- Fifteen additional verbatim source passages expose abbreviated-summary omissions for review without generating unsupported claims. Topic labels are navigation aids only.
- Future extraction instructions explicitly request named assignments and spoken weekdays. Action-field validation now requires whole-word evidence rather than matching a name inside another word.
- Optional `TRANSCRIPTION_LANGUAGE` accepts a two-letter ISO-639-1 hint for future approved requests. Default behavior and model remain unchanged. No unsupported prompt/glossary is sent to the diarization model.
- Words and punctuation in the saved transcript remain unchanged. Readability grouping already preserves source text; re-punctuating uncertain speech would create unverified edits.
