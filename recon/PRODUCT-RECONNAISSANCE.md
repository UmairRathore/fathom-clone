## Documented product, pending account verification

- Google/Microsoft calendar sync supplies upcoming meetings. Consumer-domain accounts may need a scheduled meeting within seven days to finish setup. [Quick Start](https://help.fathom.video/en/articles/276608).
- The Windows Classic desktop app can show scheduled calls and add a bot manually by meeting link. Fathom 3.0 bot-free capture is a separate experience; this account's page says it is not yet available on Windows. [Desktop App](https://help.fathom.video/en/articles/449088), [Zoom connection](https://help.fathom.video/en/articles/7573249).
- Settings cover auto-record, post-call sharing, platform connections, integrations, consent, app status, and highlight types. The live Settings UI has now been inspected; see below. [Settings](https://help.fathom.video/en/articles/3239617).
- My Calls is a personal library. Ask Fathom can appear on the right of My Calls and call detail for eligible plans. The empty library and a no-match search state have now been observed; populated results remain unverified. [Ask Fathom](https://help.fathom.video/en/articles/3239425).
- Call pages expose a recording, transcript, and summary. Sharing help places Share below the title; post-call highlight help describes a plus icon beside transcript bubbles and highlight clips to the right. Exact player/panel geometry and sync remain unverified. [Sharing](https://help.fathom.video/en/articles/295616), [Highlights](https://help.fathom.video/en/articles/295680).
- Summary types can be selected on a call. Premium/Team users can customize and regenerate. Free users receive advanced summaries for the first five calls monthly, then General/Enhanced. The account Settings selector offers sixteen template choices, though generated outputs remain unverified. [Summary customization](https://help.fathom.video/en/articles/3239809), [Free plan](https://help.fathom.video/en/articles/5290881).
- AI action items can identify assignees. Eligibility varies by plan. [Advanced AI Features](https://help.fathom.video/en/articles/640768).
- In-meeting highlights are documented for the previous experience; bot-free users currently add highlights after the meeting from transcript bubbles. This account appears to be on Classic, but in-meeting behavior remains untested. [Marking Highlights](https://help.fathom.video/en/articles/295424).
- The live Settings menu offered “Anyone with the link can view” and “Only people added can view”; documentation also describes a same-domain option in other contexts. A viewer may not need an account when access is open. No external viewer has been tested. [Sharing](https://help.fathom.video/en/articles/295616), [Viewer FAQ](https://help.fathom.video/en/articles/296128).

## Processed synthetic call and remaining limits

The user completed a two-account synthetic Google Meet test. The processed 4-minute call appeared in My Calls and was inspected at /calls/:id. The actual page has a left player plus Summary/Transcript/Ask Fathom tabs, and a right title/share, Action Items, and Annotations column. Enhanced and Project Update summaries were verified, including a percentage-based generation state. Five user-created in-meeting highlights appeared in the transcript and right annotations. Auto action-item detection returned None; adding an item from the transcript created a time-linked item and generated a title. Title search found the call, while two transcript-content queries returned No matches. The player repeatedly showed a spinner and accessibility error “Unable to play media,” preventing playback/synchronization verification. No Share modal Copy Link action or external sharing occurred; an annotation link icon was activated once with unverified effect. The complete evidence is in [Processed synthetic call reconnaissance](LIVE-CALL-RECONNAISSANCE.md) and screenshots 30–58.

**Unverified:** Working playback/sync, true two-speaker attribution, clip editing/viewer, signed-out sharing, positive transcript-content global search, responsive layout, and an hour-long eight-speaker recording. The processing state elapsed before inspection. No unrelated private meetings were opened. No internal API request/response bodies were collected.

**Inference:** The assessment demo should prioritize a coherent processed-call journey with seeded data. If live bot integration is omitted, the clone should label simulated capture/processing clearly. An hour-long, eight-speaker seed should test performance, but we have not observed Fathom's real performance at that scale.

The synthetic short meeting has been inspected. Further work should address the remaining verification gaps before application implementation. The screenshots and unanswered cases are cataloged in this directory.
